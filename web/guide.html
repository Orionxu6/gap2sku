DAILY FLOW

每次演示按这个顺序

  1. 启动服务本地开发运行 make local-up；审核链接由云端容器直接提供。
  2. 进入决策室只打开主工作台。顶部中间显示当前项目和本轮进度。
  3. 切换项目点击顶部“当前项目”，从三个已生成项目中选择；页面会同步切换 Artifact、协作事件、约束和结论。
  4. 查看员工产出用“本轮 / 决策 / 风险 / Artifact”筛选；点击产物标签查看结构化 payload，点击“展开原文”看完整交接。
  5. 查看协作记录审核快照只展示已生成的结构化事件，不接受新的消息、审批或新品输入。
  6. 展示最终方案点击右上“产品方案”，再切换内部、供应商和评委三种同源视图。

LOGIN & API

什么时候需要登录或输入 API

Decision Room / Product Story

不登录

审核快照直接访问，默认只读。老师不需要配置 API Key，也不依赖你的电脑。

Element

审核快照不开放

Element、Matrix 和 AgentTeams 仅属于完整实时运行时，不进入老师访问链接。

DeepSeek API Key

供七名文本 Worker

负责推理、聊天、工具调用和结构化交接。只通过终端安全配置，不在网页输入。

DashScope API Key

只供 Qwen 生图

Prototype Designer 仍由 DeepSeek 思考，再通过 image.generate 调 Qwen。未配置时使用明确标记的离线合成图。

不要在聊天、网页截图或日志中粘贴任何 API Key。配置文件 .env.local 由脚本以 600 权限保存并被 Git 忽略。
